三个升级方向确认

B1 模拟比赛引擎 · B2 淘汰赛晋级树 · D1 AI 球评

B1 · 模拟比赛引擎

蒙特卡洛 1000 次模拟——基于球队 stats 随机扰动，生成 1000 种可能的比分。

展示：频次分布直方图（哪组比分出现最多）、胜率重算（模拟 vs 公式预测对比）、置信区间。

实现：纯前端，不依赖额外 API。src/lib/simulation.ts + 比赛详情页嵌入

B2 · 淘汰赛晋级树

从小组赛出线 → 32强 → 16强 → 8强 → 半决赛 → 决赛的完整晋级树。

点击预测每场比赛，自动向上推算晋级者。类似 NCAA March Madness Bracket。

实现：新页面 /bracket + 递归晋级逻辑。难度最高——需要合理的小组出线规则（前2名晋级）。

D1 · AI 球评

每场比赛自动生成 100 字球评——"本场比赛的关键在于中场的控球争夺..."。

两种方案：

  • 方案 L（本地方案）：模板引擎——根据比赛数据（排名/状态/场地）动态拼接中文球评。不依赖外部 API。简单但灵活度有限。
  • 方案 A（API方案）：调用 OpenAI/Claude API 实时生成。效果好但需要 API key + 成本。

推荐先 L 后 A——模板方案今天就能上线。
