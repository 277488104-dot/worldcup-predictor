📋 设计决策汇总

视觉方向 体育媒体风（ESPN/The Athletic）+ 绿茵场色调
主色调 深绿底 (#0a180a) · 草绿强调 (#4ade80) · 金色高亮 (#f0c040)
页面范围 全部 7 个页面重设计
视觉记忆点 三层叙事：封面大图 → 数据仪表盘 → 球场纹理
动画策略 炫技拉满：视差·粒子·3D·数字动画·跑马灯·光标效果
人格策略 首页=球迷激情 ｜ 比赛/球队详情=专家冷静
实施策略 Foundation 先行 → 首页第一 → 逐页冲刺
技术栈 Next.js 14 · Tailwind CSS 3 · GSAP · ECharts · TypeScript
